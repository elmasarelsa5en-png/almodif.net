🔔 إعداد Firebase Cloud Messaging

دليل خطوة بخطوة لتفعيل Push Notifications

1 الوصول إلى Firebase Console

  1. افتح Firebase Console
  2. اختر مشروعك: almodif-49af5
  3. اذهب إلى Project Settings (⚙️ أعلى اليسار)

2 تفعيل Cloud Messaging API

  1. في الـ Settings، اختر تبويب Cloud Messaging
  2. إذا رأيت رسالة "Cloud Messaging API is disabled"، اضغط على الرابط لتفعيلها
  3. سيفتح Google Cloud Console - اضغط Enable
  4. انتظر قليلاً حتى يتم التفعيل (قد يستغرق دقيقة)

3 إنشاء Web Push Certificate

  1. في نفس صفحة Cloud Messaging، ابحث عن قسم Web Push certificates
  2. إذا لم يكن هناك مفتاح موجود، اضغط Generate key pair
  3. سيظهر لك مفتاح VAPID طويل (يبدأ بـ "B..." عادة)
  4. انسخ هذا المفتاح - سنحتاجه في الكود

4 إضافة المفتاح في الكود

افتح الملف: src/lib/firebase-messaging.ts

استبدل السطر:

const VAPID_KEY = 'YOUR_VAPID_KEY_HERE';

بـ:

const VAPID_KEY = 'المفتاح_الذي_نسخته_من_Firebase';

⚠️ تحذير مهم

  • احتفظ بنسخة من مفتاح VAPID في مكان آمن
  • لا تشارك المفتاح علناً على GitHub أو أي مكان عام
  • استخدم متغيرات البيئة (.env.local) في الإنتاج

5 اختبار الإشعارات

  1. أعد تشغيل السيرفر: npm run dev
  2. سجل دخول كموظف
  3. عند أول زيارة، سيطلب منك المتصفح السماح بالإشعارات - اضغط Allow/السماح
  4. افتح Console في المتصفح (F12) - يجب أن ترى:
    ✅ FCM: تم تهيئة Firebase Messaging ✅ FCM: تم تسجيل Service Worker ✅ FCM: تم الحصول على Device Token ✅ FCM: تم حفظ Token للموظف
  5. الآن جرب إنشاء طلب جديد - يجب أن يصل إشعار للموظف المكلف حتى لو كان المتصفح في الخلفية!

✅ تهانينا!

إذا اتبعت كل الخطوات، الآن نظام الإشعارات يعمل بكفاءة عالية:

  • ✅ الموظف يستلم إشعار حتى لو التطبيق مقفول
  • ✅ صوت قوي مع اهتزاز
  • ✅ الإشعار يفضل ظاهر حتى يتفاعل معه الموظف
  • ✅ يمكن القبول مباشرة من الإشعار

6 الخطوة التالية: Cloud Functions

لإرسال الإشعارات من الخادم (Backend) عند إنشاء طلب جديد، سنحتاج إلى:

  1. إعداد Firebase Cloud Functions
  2. إنشاء Function تُنشط عند إضافة طلب جديد في Firestore
  3. الـ Function تقرأ fcmToken للموظف المكلف وتبعت له push notification
